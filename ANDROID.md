# ShikshaSlide Studio — Android (APK) Build Guide

The web app is a full-stack Next.js + PostgreSQL application, so the Android
app is a **Capacitor WebView shell** that loads the running Next.js server.
Everything needed to build an APK with **Android Studio** is already
configured in this repository.

## 1. Prerequisites

- Node.js 18+ and `npm install` already run in this repo
- **Android Studio** (latest stable, e.g. Otter/Narwhal+) with the Android SDK
- **JDK 17+** (Android Studio's bundled JBR works)
- Android SDK **Platform 36** and **Build-Tools** (installed via
  Android Studio → SDK Manager)
- Environment variables (add to `~/.zshrc` / `~/.bashrc`):
  ```bash
  export ANDROID_HOME="$HOME/Library/Android/sdk"        # macOS
  export ANDROID_HOME="$HOME/Android/Sdk"                # Linux
  export ANDROID_HOME="%USERPROFILE%\\AppData\\Local\\Android\\Sdk"  # Windows
  export PATH="$PATH:$ANDROID_HOME/platform-tools:$ANDROID_HOME/cmdline-tools/latest/bin"
  ```

## 2. Run the web app server (the APK loads this)

The APK needs a reachable Next.js server:

```bash
npm run build
npm run start          # serves on http://localhost:3000 (uses .env DATABASE_URL)
```

- **Android emulator:** the app defaults to `http://10.0.2.2:3000`
  (`10.0.2.2` maps to the host machine's `localhost`).
- **Physical device:** use your computer's LAN IP, e.g.
  `http://192.168.1.10:3000`, and allow port `3000` in your firewall.
- **Production:** deploy the Next.js app (Vercel, Docker, VPS…) and use its
  HTTPS URL.

You can bake the URL into the app at sync time:

```bash
CAPACITOR_SERVER_URL=http://10.0.2.2:3000 npx cap sync android
# or
CAPACITOR_SERVER_URL=https://your-deployed-app.example.com npx cap sync android
```

If `CAPACITOR_SERVER_URL` is **not** set, the APK opens the bundled
`www/index.html` shell first, where the teacher can enter/save the server URL
once (persisted in WebView `localStorage`) and tap **Launch Studio**.
Open the shell with `?reset=1` to change the saved server.

## 3. Build the APK

### Option A — command line (fastest debug APK)

```bash
npm run apk:debug
# Output: android/app/build/outputs/apk/debug/app-debug.apk
```

Release APK / AAB (signing is configured in Android Studio, see below):

```bash
npm run apk:release    # android/app/build/outputs/apk/release/app-release-unsigned.apk
npm run aab:release    # android/app/build/outputs/bundle/release/app-release.aab (Play Store)
```

### Option B — Android Studio (recommended for a signed APK)

```bash
npx cap open android        # or: npm run cap:open:android
```

In Android Studio:

1. Wait for Gradle sync to finish (bottom status bar).
2. Select a device/emulator in the toolbar, or **Device Manager → Create Device**
   (e.g. Pixel 8, API 36).
3. Press **Run ▶** for a debug build, or:
4. **Build → Generate Signed Bundle / APK… → APK → Next**
   - Create a new keystore (or pick an existing one), e.g.
     `~/shikshaslide-key.jks`, store/key passwords, alias `shikshaslide`
   - Choose **release** build variant → **Finish**
   - Signed APK lands in `android/app/build/outputs/apk/release/app-release.apk`

### Install on a device

```bash
adb install android/app/build/outputs/apk/debug/app-debug.apk
# or drag the APK onto a connected phone with USB debugging enabled
```

## 4. Useful npm scripts

| Script | What it does |
| --- | --- |
| `npm run mobile:build` | `next build` + `cap sync android` (refresh web assets) |
| `npm run cap:sync` | Sync `www/` + plugins into the `android/` project |
| `npm run cap:copy` | Copy web assets only |
| `npm run cap:open:android` | Open the project in Android Studio |
| `npm run cap:run:android` | Build, install and launch on a connected device/emulator |
| `npm run cap:assets` | Regenerate icons/splash from `resources/` |
| `npm run apk:debug` / `apk:release` / `aab:release` | Gradle APK/AAB builds |

## 5. Project layout

```
capacitor.config.ts                     # appId com.shikshaslide.studio, webDir=www, plugins
www/index.html                          # WebView shell (server URL picker + redirect)
resources/                              # icon.png, icon-foreground/background.png, splash*.png
android/                                # Native Android Studio project (generated by Capacitor)
  app/src/main/AndroidManifest.xml      # INTERNET permission, cleartext traffic, adjustResize, deep links
  app/src/main/java/.../MainActivity.java  # BridgeActivity (Capacitor WebView)
  app/build.gradle                      # applicationId, versionName 1.0.0
src/lib/capacitor.ts                    # In-app bridge: splash hide, status bar, back button, network status
```

## 6. Native behaviors already wired in the app

- Splash screen hidden once the web app boots; status bar themed dark/light
  with the UI mode toggle.
- **Hardware back button:** closes the presentation editor → closes the
  sidebar → exits the app.
- **Real device connectivity** (`@capacitor/network`) drives the
  Online/Offline badge; offline edits persist in IndexedDB/localStorage and
  auto-sync to PostgreSQL when the server is reachable again.
- Cleartext HTTP allowed (`usesCleartextTraffic`) so `http://10.0.2.2:3000`
  and LAN-IP dev servers work; `windowSoftInputMode="adjustResize"` keeps
  text inputs visible above the keyboard.
- Deep links: `shikshaslide://…` open the app.

## 7. Changing the server URL later

- Re-sync with a new URL: `CAPACITOR_SERVER_URL=http://192.168.1.20:3000 npx cap sync android`
  then rebuild the APK.
- Or, if the shell mode is used: open the app once, clear the saved URL by
  visiting the shell with `?reset=1` (or clear app data in Android Settings →
  Apps → ShikshaSlide Studio → Storage → Clear data) and re-enter the URL.

## 8. Troubleshooting

- **Blank white screen in APK:** the Next.js server isn't reachable from the
  device/emulator. Check the URL in the shell, the firewall, and that
  `npm run start` is running. In Android Studio: Run → **Logcat**, filter
  `chromium` for WebView console errors (WebContents debugging is enabled).
- **Gradle sync fails:** open SDK Manager and install Platform 36 + Build-Tools;
  set `ANDROID_HOME`; File → Sync Project with Gradle Files.
- **`local.properties` missing:** Android Studio creates it automatically once
  `ANDROID_HOME` is set; you can also create it manually with
  `sdk.dir=/path/to/Android/Sdk`.
- **API calls fail inside the APK:** the app calls relative `/api/*` routes,
  so they always hit the same origin as the loaded page — make sure the
  server URL points at the Next.js server (not a static host).
