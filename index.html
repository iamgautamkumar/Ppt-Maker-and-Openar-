ShikshaSlide Studio

AI PPT Maker & Presentation Editor for Online Teachers

Android emulator: use http://10.0.2.2:3000 (maps to your computer).
Physical device: run npm run build && npm run start on your computer and enter its LAN IP, e.g. http://192.168.1.10:3000 (allow port 3000 in the firewall).
Or deploy the Next.js app and enter its HTTPS URL.
Open the shell with ?reset=1 to change the saved server.
